**Oct 2025 — Present**

Agent architecture for a deployed personalized training platform serving 20 users. Retrieval grounds plans in professional training guidelines and workout history; an evaluation-feedback loop checks constraints and consistency.

## Technical work

- Designed the agent loop, interaction interfaces, role decomposition, and prompt system for a personalized training platform serving 20 users.
- Grounded generated plans in professional team-training guidelines and historical workout plans using retrieval-augmented generation.
- Added an evaluation-feedback loop to review safety, reliability, constraint satisfaction, and consistency.
- Contributed as a co-inventor to the underlying invention patent, currently under substantive examination.


**Technologies / topics:** RAG, Agent design, Evaluation
