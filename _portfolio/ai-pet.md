**Jul 2026 — Present**

A desktop companion with a tool-using agent loop and persistent personality. An evidence-governed memory pipeline combines structured updates, deterministic validation, and hybrid retrieval to keep context across sessions.

## Technical work

- Built an Electron-based companion agent with an agent loop for local file operations, command-line execution, browser search, retries, and fallback paths.
- Separated raw conversations, evidence-backed events, user claims, topic continuity, open loops, and self/relationship state in layered long-term memory.
- Used LLM-proposed structured updates with deterministic provenance checks, conflict resolution, and transactional SQLite updates.
- Combined lexical, semantic, and structural retrieval signals with weighted reciprocal-rank fusion, conditional reranking, deduplication, and context-budget-aware packing.
- Added permission confirmation, execution auditing, context compaction, and daily memory consolidation.


**Technologies / topics:** Electron, SQLite, LLM agents
